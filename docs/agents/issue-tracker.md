# Issue Tracker: Linear

Issues and specs for this repo live in Linear.

## Location

- **Team:** `My Projects`
- **Project:** `Plait.nvim`

When creating or updating work for this repo, scope it to the `My Projects` team and `Plait.nvim` project.

## Conventions

- **Create an issue:** Create it in the `My Projects` team and attach it to the `Plait.nvim` project.
- **Read an issue:** Fetch the issue by its Linear identifier, including its description, state, labels, comments, and relations when relevant.
- **List issues:** List issues scoped to the `My Projects` team and `Plait.nvim` project, using state and label filters as appropriate.
- **Comment on an issue:** Add a comment to the Linear issue.
- **Update an issue:** Change its state, assignee, labels, project, or description in Linear as needed.
- **Close an issue:** Move it to the team's completed or canceled state as appropriate.

## When a skill says "publish to the issue tracker"

Create a Linear issue in the `My Projects` team and `Plait.nvim` project.

## When a skill says "fetch the relevant ticket"

Fetch the referenced Linear issue by identifier, including comments.

## Wayfinding operations

Use one Linear issue as the map and child issues as tickets. Record blocking relationships with Linear's native issue relations where available. Keep decisions and the current frontier in the map issue description or comments.
